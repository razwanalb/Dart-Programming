# Practice (Advanced)

1. Create a student list.

```
["Rahim", "Karim"]
```

Insert "Razwan" at index 1.

Expected Output:

```
[Rahim, Razwan, Karim]
```

---

2. Create a product list.

```
["Keyboard", "Mouse"]
```

Use insertAll() to insert:

```
Monitor
Speaker
```

at index 1.

Expected Output:

```
[Keyboard, Monitor, Speaker, Mouse]
```
